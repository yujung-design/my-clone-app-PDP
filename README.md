# SSOOOK-style PDP Generator

쏘오옥(SSOOOK) 상품 상세페이지의 **레이아웃·타이포·섹션 구조**를 참고해,  
상품명·가격·설명·이미지 URL을 넣으면 완성 HTML이 나오는 로컬 웹툴입니다.

## 실행

Node.js만 있으면 됩니다 (추가 npm 패키지 없음).

```bash
npm start
```

브라우저에서 http://localhost:3456 열기.

또는 `public/index.html`을 브라우저로 직접 열어도 동작합니다.

## 기능

- 좌측 입력 폼 → 우측 실시간 미리보기
- **HTML 복사** / **다운로드** (`product-detail.html`) / **새 탭**
- **샘플 채우기** 버튼으로 데모 데이터 로드
- 에디토리얼 섹션, FAQ, 컬러/사이즈 옵션, 배송 공지 지원
